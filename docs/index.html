Psychomatrix Lab

Measure a contextual illusion on a target that is also hard to see. The context (a tilted surround, or inducer circles) stays at full contrast; only the target is degraded by low contrast or noise, while the reference stimuli stay clean. Standard 2AFC compares the target with one reference. The psychomatrix method shows the target with two references and asks which reference matches the target? Run both side by side on a simulated observer whose true parameters you set, or try them yourself.

How the model works

The observer encodes the target as t̂ ~ N(t + b, σt²) and each reference as r̂ ~ N(r, σr²), then picks the reference whose estimate lies closer to t̂. With u = r1 − r2 and v = r1 + r2 − 2t, the probability of choosing r2 is

P(r₂) = Φ(u/σᵤ)·Φ((v−2b)/σᵥ) + [1−Φ(u/σᵤ)]·[1−Φ((v−2b)/σᵥ)] σᵤ = √2·σᵣ σᵥ = √(2σᵣ² + 4σₜ²)

This surface over all (r1, r2) pairs is the psychomatrix. Its spread across the diagonal depends only on σr, its spread along the diagonal mixes in σt, and its anti-diagonal sits at r1 + r2 = 2b. All three parameters are therefore identifiable. Both references share the same contrast and context, so a preference for the clearer stimulus has nothing to act on.

Fitting uses a grid posterior over (b, σr, σt) with a 2% lapse rate. Trial selection minimises the expected posterior entropy, as in optimaltrial.m, and draws at random among the four best pairs to avoid repeating the same triplet.
